# 2026 DHIA Transportation · Smart ON-BOARD Solution

来源：GKS 资料包 `2026-DHIA-Transportation.zip`  
原文：`DHIA - Transportation-Smart ON-BOARD solution 2026.pdf`（27 页 PPT，作者马成林，2026-06-12）  
对应 GKS 目录：`category_id=168159`

这是大华（DHIA）面向交通行业的 **车载智能解决方案**，不是固定点安防。三条主线：公交、校车、货车；共用车载主机 + 主动安全 + 客流/货物感知 + 中心平台。

---

## 1. 方案在解决什么

行业从 GPS → CCTV → AI 主动安全 → 数据驱动安全 → 自动驾驶。当前客户痛点是三类：

| 维度 | 痛点 | 方案目标 |
|---|---|---|
| Safety | 疲劳/超速/急刹、盲区、复杂路况 | 零事故，全链路监控 |
| Revenue | 司机逃票、优惠卡盗刷、收入来源窄 | 客流核对、广告、罚单 |
| Efficiency | 人工排班空驶、油耗保险高、数据孤岛 | 多式联运、智能调度 |

---

## 2. 三条场景

```
车端（摄像头 + 主机 + 屏 + 传感器）
        │ 4G
中心（Server / Client / Storage / Decoder / Display / APP）
        │
应用：客流趋势、告警统计、主动安全、电子围栏与线路、司机画像
```

### 公交 Smart Bus
- **客流统计**：双目客流相机对进出人数，和票务系统对账，抓逃票/司机截留票款
- **人脸 + 优惠卡**：刷折扣卡时抓拍，IVSS 比对持卡人（PPT 写识别率约 96%），防盗刷
- **站台导乘与广告**：下一班车、线路、票价、广告，增加收入

### 校车 Smart School Bus
- **学生滞留检测**：司机下车确认按钮 + PIR 红外；忘按或有人则声光告警并上报
- **STOP ARM**：停靠伸臂后，对违规超车车辆抓拍车牌取证罚款
- 还配 DSM / ADAS / 360 环视 / IPC / 7 寸屏

### 货车 Smart Truck
- **车队管理**：GPS 高频定位、电子围栏、油耗与维保
- **主动安全**：DSM + ADAS + 360 环视 + 后视
- **货舱**：温感、门磁、烟感、体积测量相机
- **降本**：驾驶行为控油、视频证据降保险欺诈、远程车况预维保

注意：

1. PPT 写 `DAE-CVS5122`，ERP 是 **`CSV5122`**（S/V 对调），查料号用 CSV。
2. PPT 写 `MXVR8212`，订货要落到 `DHI-DAE-MXVR8212-GFWI`（GPS/4G/Wi-Fi 版本）。
3. `HMW8441X-M` vs `-M12` 是接头不同（航空头 M12 / 普通 M），客流相机两个 SKU。
4. DSM / ADAS / 后视 / 体积测量相机在 PPT 里是角色名，没有写死单一料号；同族车载枪/半球在 `1.0.01.02` 的 `HDBW3231/4431/5241`、`CPC5241`、`CDM/CFM/CBS` 等里选。

## 4. 成功案例（方案证明点）

| 项目 | 规模 | 要点 |

## 5. 报价/投标时怎么用 0922

1. 方案对外写 PPT 型号（`MXVR8212`、`IPC-HMW8441X-M12`）。
2. 配置表写成 0922 **内部型号**（镜头、M/M12、GFWI、4 路/8 路环视）。
3. 合同与备货用 **料号** `1.0.01.02.*`。
4. 一个外部型号仍可能对应多个料号（PANA-S02 的 04/08 路，MXVR 的 2.0 版本）。

查询：

```bash
python3 -m src.dahua_identity lookup MXVR8212
python3 -m src.dahua_identity lookup HMW8441
python3 -m src.dahua_identity lookup PANA-S02
```

## 2. 法国频率（表里的坑）

表把三种载波都标成 **European Standard** 电源/区域，**不等于法国能用**：

| 载波 | 表里的标签 | 法国 |
|---|---|---|
| **868.0–868.6 MHz** | European Standard | **用这个**（`W2(868)` / `FW2(868)` / `GW2(868)`） |
| 433.1–434.6 MHz | 同样写 European Standard | **不要写进法国 CCTP / 报价** |
| 915.0–928.0 MHz | 部分 Hub 2 行也写 European Standard | 不是法国 SRD；不要当 EUR |

Power Supply 列的 European vs American 是 **电源插头/LTE 频段**，不是 868 vs 433。  
4G 欧标：LTE-FDD B1/B3/B5/B7/B8/**B20**，TDD B38/B40/B41。美标没有 B20，有 B2/B4/B28。

英国电源另开料号 `1.2.19.07.10255`，**0922 没有**。美标 Hub 2 电源 `1.0.01.19.10851` / `10852` 也没有。

## 3. 套装组成与认证

每套都是 **主机 + PIR + 门磁 + 遥控器**（各一件）。Hub 2 写明：

- 主机 `ARC3800H-W2`
- PIR `ARD1233-W2`
- 门磁 `ARD323-W2`
- 遥控器 `ARA24-W2`

这些单品的 868 料号在 [`gks-dss-alarm.md`](gks-dss-alarm.md) §4.2 / `gks-dss-alarm-bom.csv`，**在 0922 里**。套装料号是另一组 `ART-ARC…`。

表内原话：

- **EN50131 Grade 2 只针对 868 MHz 机型**（Hub 2）
- **KIT is not individually certified**（套装本身没有单独证书，要看套内各件）
- Hub 2 CE「Q2 才有」——表是选型快照，不以本表当已取证

`-B` = 黑色外观。`Model C` = 白盒包装。无 `DHI-` 前缀的 `ART-ARC…` 是另一套包装/渠道料号，法国报价优先 **DHI-**。

## 9. 设计院怎么用

| 对象 | 用 | 不用 |
|---|---|---|
| D 类零售 / 经销商 BE | Hub 2 **868 DHI** 套装 `11086-0001` 或 `11088-0001`；单品仍按 0922 无线表 | 433 套装、无 DHI 前缀 `ART-`、V3 3000H 新料号 |
| 小三产 / 住宅 | 同上，或拆套装下 868 单品 | 把 KIT 写成已 EN50131 整机认证 |
| Assystem / 工业有线 | 主机仍 `ARC3008C`；有线探头除 `ARD312` 外先当 **选型-only** | 把 `1.0.99.81.10036` 当 ARD1233 库存 |
| 校园 / 停车场求助 | `VTA8311A*` `-9001` | 把 `-V2` 4G 模块当已可订 |
| 消防 | 无线烟感走 `HY-SA21A-W2(868)` | FAD201A、把烟感写进入侵防区当合规 |

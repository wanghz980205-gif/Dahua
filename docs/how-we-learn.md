# 设计院知识怎么学（执行法）

原则：**只学能写进 CCTP / 能下料号的东西**。官网通读、总部宣传片不算学完。

**分工定死**：你从 GKS（VPN）或内部盘丢 zip；我消化进本仓库，做成可查询表 + 拜访卡 + 法语 CCTP 段。这个环境进不了公司 VPN，不要指望我自己登录 GKS。

---

## 本周只做一件事

先丢 **门禁 + 平台（DSS/IVSS）** 两个 GKS 资料包。没有这两包，设计院只能把我们写成「摄像机供应商」。

对话里直接贴 zip。文件名尽量写成：

```
FR-Access-<日期>.zip
FR-DSS-<日期>.zip
```

有就一起丢、没有就先丢有的。不要再丢总部总册。

---

## 四包，按顺序

### 包 1 — 产品弹药（设计院图②）

**目的**：五块都能写出法语功能段 + 0922 外部型号 + 料号。

| 你丢什么 | 我学成什么 |
|---|---|
| GKS 法国可售：视频 / 门禁 / 入侵 / 平台 资料包 | 每块一张「CCTP 可抄段落 + 外部型号 + 料号」 |
| 法语规格书、已用过的 CCTP 摘录 | 对照 APSAD R82、RGPD、ONVIF，标哪些能写、哪些不能写人脸 |
| France / EUR 可售或价目（Excel 即可） | 过滤 0922，只保留法国能订的内部型号 |

没有 zip 时，仓库里只有 0922 + 车载方案，**门禁 / 入侵 / 平台写不出来**。

GKS 建议下：`Access` `Alarm` `DSS` `IVSS`，以及 France/EUR 价目。

### 包 2 — 目标卡片（图⑥ 点名）

**目的**：拜访前 10 分钟知道找谁、带哪套材料。

方法：公开信息我先做一页卡 → 你们补对接人和在谈项目。

A 类已起稿（见 [`target-cards-grands-groupes.md`](target-cards-grands-groupes.md)）：Ingérop、Egis、Artelia、Setec、Systra、Oteis、Assystem；C 类 UGAP。

B/D 不一次做 100 家。你们标「本季度要拜访的各 5 家」后再做短卡。

### 包 3 — 法国合规（否则 CCTP 被删）

公开骨架已能学：APSAD R82/D32、CNPP、RGPD/CNIL、ANSSI 视频指南、2007-08-03 政令、NF EN 62676。

还缺内部的：**哪些型号有 CNPP Certified / 法语符合性声明**。丢一份认证表或 GKS「certification France」文件夹。

### 包 4 — 渠道落地（图④ D + national partner）

把「谁出图、谁供货」写成三条路径：

1. A/B 设计院出图 → 指定 national partner 施工 → 代理商备货  
2. C UGAP → 框内集成商下单（厂商一般不直接中框）  
3. D 经销商 BE 出图 → 安装商（零售盘）

需要：national partner 名单、Tevah 等代理商自有 BE 怎么配合。一张 Excel 就够。

## 你怎么丢材料（格式）

| 包 | 文件名示例 | 内容 |
|---|---|---|
| 1 | `FR-Access-20260923.zip` | 门禁 datasheet / 安装手册 / 法语 PDF |
| 1 | `FR-Alarm-20260923.zip` | 入侵报警 |
| 1 | `FR-DSS-20260923.zip` | DSS / IVSS / 平台 |
| 1 | `FR-EUR-sellable.xlsx` | 法国/欧洲可售内部型号或料号 |
| 3 | `FR-CNPP.xlsx` 或 zip | 认证、符合性声明 |
| 2/4 | `FR-visits-Q4.xlsx` | 本季拜访：名称、A/B/C/D、对接人（可空） |
| 4 | `FR-national-partners.xlsx` | 重点集成商 + 对应代理商 |

一次一个 zip 也可以。我收到后对照 0922 落料号，**绝不编造料号**。

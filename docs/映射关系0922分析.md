# 大华产品标识映射（基于《映射关系0922》）

学习日期：2026-09-22  
数据源：`data/映射关系0922.xlsx`（Sheet1）

这份表回答的是渠道/订单里最常见的三个问题：

1. 这个**料号**对应哪台机器？
2. 工厂/订货用的**内部型号**和客户看到的**外部型号**差在哪？
3. 所谓 **SKU** 在大华体系里到底指哪一层？

表里**没有单独的 SKU 列**。SKU 不是第四种编码，而是对「可库存、可订货单元」的叫法，在本表中分别落在料号和内部型号上。

---

## 1. 四个概念对照

| 业务叫法 | 本表字段 | 典型值 | 粒度 | 用途 |
|---|---|---|---|---|
| **料号** | `Part No.` | `1.0.01.04.31634-0016` | 最细，一物一码 | ERP / 云商 / 进出存 / 报价行 |
| **内部型号** | `Internal Model` | `DH-IPC-HCBW8442P-0250B-EUR` | 订货配置（镜头、区域、电源、版本） | 工厂、BOM、订货、最接近销售 SKU |
| **外部型号** | `External Model` | `DH-IPC-HCBW8442P` | 产品族 / 规格书型号 | 官网、彩页、投标参数、客户沟通 |
| **SKU** | （无独立列） | 库存 SKU = 料号；订货 SKU = 内部型号 | — | 库存按料号；下单按内部型号 |

一张图：

```
外部型号  1 ── N  内部型号  1 ── N  料号
(目录型号)         (含镜头/区域/电源)     (ERP 物料)
   │                    │                  │
   └─ 客户看到的名字     └─ 订货 SKU         └─ 库存 SKU
```

本表实测基数（去重前 22,359 行，去重后 20,301 条；唯一料号 20,295）：

| 关系 | 结论 |
|---|---|
| 1 个料号 → 内部型号 | 几乎总是 1（仅 5 个料号有 2 个内部型号，属于空值/脏数据） |
| 1 个料号 → 外部型号 | 几乎总是 1 |
| 1 个内部型号 → 料号 | 平均 2.1，最多上千（空内部型号、渠道硬盘、NVR 版本） |
| 1 个外部型号 → 内部型号 | 平均 1.22；1,473 个外部型号对应多个内部型号 |
| 1 个外部型号 → 料号 | 平均 2.16 |
| 内部型号 = 外部型号 | 约 54%（配置信息没有再拆一层） |
| 内部型号 ≠ 外部型号 | 约 46%（内部比外部多镜头 / 区域 / 电源 / P 位 / 版本） |

## 2. 料号（Part No.）

### 2.1 形态

```
A.B.C.D.E[-后缀]
```

例子：

- `1.0.01.04.31634` — 基础成品料号
- `1.0.01.04.31634-0016` — 同一成品的配置/批次变体
- `1.0.01.04.42099-9001` — 常见 `-9001` 组织/区域变体

两种主形态：

- `A.B.C.D.E`：约 8,358 行
- `A.B.C.D.E-NNNN`：约 7,482 行

高频后缀：`-9001`（2,950）、`-9002`（763）、`-0001`～`-0016`、`-9901`。  
`-9001` 与无后缀的基础料号同时存在时，内部型号几乎总是相同（513 对里 510 对一致）——后缀多半是销售组织/工厂/包装维度，不是换了一款机器。

### 2.2 前几段含义（由产品族反推）

`1.0` 占绝大多数（19,296 行），是成品。

第四段和产品大类高度对应：

| 料号前缀 | 主要产品族 | 约行数 |
|---|---|---|
| `1.0.01.04` | IPC 网络摄像机 | 4,220 |
| `1.0.01.23` | NVR | 3,059 |
| `1.0.01.01` | XVR / HCVR | 3,117 |
| `1.0.01.12` | HAC 同轴摄像机 | 1,778 |
| `1.0.01.07` | SD 球机 | 974 |
| `1.0.01.15` | VTO 门口机 / VTH 室内机 | 1,272 |
| `1.0.01.25` | 门禁/考勤（ASI/ASC/ASR/ASA/ASG） | 298（去重后） |
| `1.0.01.13` | DSS 平台硬件 | 24 |
| `1.0.01.19` | 入侵报警（ARC/ARD/ARA…） | 287 |
| `1.0.01.18` | IVS 分析服务器 | 3（几乎空；GKS 另有 P/N 不在本表） |

## 3. 内部型号 vs 外部型号

### 3.1 内部型号多出来的东西

当两者不同时，内部型号几乎总是「外部型号 + 配置」。高频附加段：

| 附加段 | 含义 | 例子 |
|---|---|---|
| `0280B` / `0360B` / `0250B` / `0200B` / `0600B` | 定焦镜头订货码（2.8 / 3.6 / 2.5 / 2.0 / 6.0 mm） | `…-0280B` |
| `27135` / `2712` / `0832` / `0856` | 变焦镜头焦段 | `…-Z-2712` |
| `EUR` / `US` / `DE` / `AL` / `DAE` | 区域/认证 | `…-0250B-EUR` |
| `AC220V` / `DC12AC24V` | 供电 | `…-AC220V` |
| `S2` / `S3` / `S5` / `S6` / `V2` / `V3` | 硬件/软件世代 | `…-S2` |
| `DIP` | 拨码/特定规格包 | `…-S3-DIP` |
| `imou` / `white` / `blue` | OEM 或颜色 | `…-imou` |
| 体号中的 `P` | 工厂位，对外常去掉 | `EBW8842P-AS` → `EBW8842-AS` |
| `DH-KIT/` | 套装包装 | 内部是 KIT，外部是单机型号 |

### 3.2 不能只做「截断」

约一半行可以直接把内部型号截到外部型号；另一半会改写，例如：

| 内部型号 | 外部型号 | 发生了什么 |
|---|---|---|
| `DH-IPC-HCBW8442P-0250B` | `DH-IPC-HCBW8442P` | 去掉镜头 |
| `DH-IPC-HCBW8442P-0250B-EUR` | `DH-IPC-HCBW8442P` | 去掉镜头 + 区域 |
| `DH-IPC-HDW8441XP-3D-0280B` | `DH-IPC-HDW8441X-3D` | 去掉 `P`，去掉镜头 |
| `DH-IPC-HFS8449GP-Z-LED-0856-AC220V` | `DH-IPC-HFS8449G-Z7-LED` | `P` 去掉；`Z-0856` 改写成 `Z7` |
| `DH-IPC-HDBW8841HP-Z-LB-0832-DC12AC24V` | `DH-IPC-HDBW8841H-Z4-LB` | `Z-0832` → `Z4` |
| `DH-IPC-EBW8842P-AS-IVC` | `DH-IPC-EBW8842-AS-IVC` | 仅去掉体号里的 `P` |
| `DH-KIT/IPC-HUM8441EP-E1-L1-0280B-S3` | `DH-IPC-HUM8441E-E1-L1` | 去掉 KIT/P/镜头/世代 |
| `IPC-HFW2449SP-S-IL-0280B` | `IPC-HFW2449S-S-IL-0280B` | 去掉 `P`；海外外部型号可无 `DH-` |

所以：**内部 → 外部必须查表，不能靠正则 100% 还原。**

### 3.3 前缀 `DH-` / `DHI-`

- `DH-`：国内品牌型号（内部约 9,078）
- `DHI-`：国际/出口型号（内部约 8,820）
- 无 `DH` 前缀：海外规格书写法、配件、OEM、硬盘型号等

同一台机器可能同时以 `DH-IPC-…` 和 `IPC-…` 出现，外部型号以表里登记的为准。

## 4. SKU 怎么用

在本项目的九月业务语境里，按下面三层用，不要混：

1. **对库存、对账、进出货**：SKU = **料号**  
   例：仓库里的一箱货是 `1.0.01.04.37895-0011`，不是 `DH-IPC-HDW8441X-3D`。
2. **对订货、对工厂、对配置**：SKU = **内部型号**  
   例：要 2.8mm 还是 2.0mm、欧版还是通用版，看内部型号。
3. **对客户、对方案、对投标**：只报 **外部型号**  
   例：投标写 `DH-IPC-HDW8441X-3D`，中标后再落到具体内部型号和料号。

错误用法：拿外部型号当唯一库存码。一个外部型号平均对应 2+ 个料号，镜头和区域不同，货不是同一个。

## 5. 完整例子

同一外部型号 `DH-IPC-HCBW8442P`：

| 料号 | 内部型号 | 说明 |
|---|---|---|
| `1.0.01.04.31634` | `DH-IPC-HCBW8442P-0250B` | 基础成品，2.5mm |
| `1.0.01.04.31634-0016` | `DH-IPC-HCBW8442P-0250B` | 同配置的料号后缀变体 |
| `1.0.01.04.39197` | `DH-IPC-HCBW8442P-0250B-EUR` | 欧版 |

同一外部型号 `DH-IPC-HDW8441X-3D`：

| 料号 | 内部型号 |
|---|---|
| `1.0.01.04.37894` / `…-0007` | `DH-IPC-HDW8441XP-3D-0200B` |
| `1.0.01.04.37895` / `…-0011` | `DH-IPC-HDW8441XP-3D-0280B` |

外部型号只说「这是 8441X 双目 3D 海螺」；2.0mm 还是 2.8mm 在内部型号和料号上才分开。

## 6. 数据质量（查表时要避开）

| 现象 | 数量 | 处理 |
|---|---|---|
| 完全重复行 | 2,058 | 已在 `data/mapping-0922.csv` 去重 |
| 内部型号为空 | 1,080 | 配件、物料、折扣、物料描述写在外部型号里 |
| 外部型号为空 | 328 | 只有料号或内部型号 |
| `External Model = Discount` | 206 | 料号 `1.4.01.07.*`，无真实型号 |
| `Internal Model = HDD-CHANNEL` | 55 | 外部型号才是具体硬盘（WD/Seagate） |
| 内部为空、外部是宣传品尺寸/Polo 衫 | 一批 | 市场物料，不是摄像机 |

查产品时：内部、外部都空，或外部为 `Discount` / `/` 的行，不当作设备映射。

## 7. 查询约定

工具：`python3 -m src.dahua_identity lookup <关键词>`

- 输入料号 → 返回内部型号、外部型号
- 输入内部型号 → 返回所有料号和外部型号
- 输入外部型号 → 返回该目录型号下全部可订货内部型号和料号
- 输入片段（如 `HFW3849`、`1.0.01.04.37895`）→ 模糊匹配

映射文件：`data/mapping-0922.csv`（去重后的权威表）。原始 Excel 保留在 `data/映射关系0922.xlsx`。

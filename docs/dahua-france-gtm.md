# Dahua Technology France · 公司与渠道

记录日期：2026-09-23  
来源：法国分公司内部说明 + 公开登记信息

## 我们是谁

- **主体**：Dahua Technology France（大华法国分公司，厂商侧）
- **位置**：Rueil-Malmaison（92）
- **角色**：不是集成商，是 **OEM/厂商法国公司**。卖货、赋能渠道、做大项目与设计院前置，不替代下游施工。

## 销售链路

```
Dahua France（厂商）
    → 代理商 Distributeur（压货、物流、对安装商开户）
        → 集成商 Intégrateur / 安装商 Installateur
            → 甲方 Maître d'ouvrage
```

补充：

- **National partner**：大型集成商是重点，不只走批发。他们拿全国/大区框架、能进 Ingérop / Assystem 图纸里的标。
- **零售/中小安装商**：目前相对强（摄像头+录像机标准盘）。
- **交通**：有基础，还不是主力。
- **其它垂直**（能源工业、楼宇、交通路侧、轨交）：要靠设计院和 national partner 往上做。

公开渠道页上的分销商包括 By Demes、CCF、SmartSD、Tevah Systèmes 等（以官网当时名单为准）。

## 设计院在链路里的位置

设计院（bureau d'études / MOE / AMO）**通常不采购设备**，但在 AVP/PRO 阶段把参数写进 CCTP。  
牌子一旦写进 CCTP（或写成「等效于某某性能」），后面的集成商只能按图供货。

所以法国分公司对 Ingérop、Assystem 的工作，是 **出图前锁定规格**，不是零售推套装。

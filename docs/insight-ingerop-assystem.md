# 法国市场 · 设计院洞察（Ingérop / Assystem）

适用：Dahua Technology France，2026 年拓展设计院与交通/工业项目。  
已对齐：渠道模型（代理商 → 集成商/安装商 → 甲方）、车载方案 2026、0922 料号规则。

---

## 1. 先把角色分清

| 对象 | 他们要什么 | 我们不能怎么做 |
|---|---|---|
| 安装商 / 零售 | 有货、价格、易装、App | 不要塞 27 页总部方案 |
| National partner 集成商 | 可投标 BOM、供货周期、技术支持、框架价 | 不要绕过他们直接给甲方报价抢单 |
| 设计院 Ingérop / Assystem | **可写进 CCTP 的参数、认证、参考项目、CAD/BIM 图块** | 不要讲品牌故事；他们要 NF EN 62676、RGPD、ANSSI、APSAD R82 |
| 甲方 | 合规、运维、不踩 CNIL | 见面太晚，规格已被设计院写死 |

法国视频项目真正锁单的文件是 **CCTP**（加上 APSAD R82 / D32 网络安全、CNIL 视频指引、内政部 2007-08-03 视频保护技术令）。设计院写的是功能与性能，很少写死一个中国内部型号；但他们会写「等效于」某分辨率、像素密度、ONVIF、PoE、网管、存储天数。我们要把 **外部型号 + 法语规格书** 交给他们，0922 内部型号/料号留给集成商下单。

## 2. Ingérop：优先对象

**为什么像我们**

- 总部也在 **Rueil-Malmaison**，和 Dahua France 同城，便于做工程师层面的日常。
- 独立工程集团，约 3500 人，业务含建筑、水、能源、工业、基建、交通、城市。
- 内部有 **Mobilités / Équipements et Systèmes**：弱电（视频、对讲、门禁）、电信、GTC/超融合、**票务与 SAEIV**。他们自己招人做 EP → AVP → PRO → ACT，以及 VISA/EXE/DET/AOR。
- 已经在做 **路网视频监控 MOE**（例如 DIR Ouest、南特环路交通摄像机站点）。这类项目下游才是集成商供货。

**他们会写进图的场景（按接近程度）**

1. **路侧 / 交通视频**（最贴他们现有合同）：枪机、球机、补光、传输、机柜，不是车内 MXVR。
2. **枢纽 / 场站 / 停车场 / 公交场**：客流、周界、站台信息，可挂上 HMW8441 客流、IVSS，但要用场站语言而不是「土耳其公交」。
3. **车载公交/校车/货车**：只有当他们做 SAEIV / 车队 / 运营商项目时才进。不要把 2026 ON-BOARD PPT 当见门礼物。
4. **楼宇弱电**：零售优势可转化成「标准 IPC+NVR 可被 PRO 引用的参数表」。

**怎么合作（厂商正确姿势）**

- 找 MES / 弱电负责人，提供 **法语产品数据表 + 典型 CCTP 段落（功能描述，不写死唯一品牌）+ EUR 订货型号**。
- 给 national partner 一份「Ingérop 图纸出现后如何 0922 下单」对照，避免设计院写 `MXVR8212`、采购却订不到 `DHI-DAE-MXVR8212-GFWI`。
- 用法国或欧盟参考（有更好）；总部土耳其/阿联酋案例只作能力证明，不能当 CCTP 依据。

## 3. Assystem：第二条线，话术要换

Assystem 是核电/能源/工业工程为主（EDF、Orano、EPR、ITER），交通侧偏 **SNCF 路网、氢能列车、场段**，不是公交运营商方案公司。

他们的图纸语言是：**sûreté、网络安全、ATEX、ICPE、ANSSI 思路、生命周期与配置管理**。  
见面不要先讲学生滞留检测或站台广告。

**可切入**

- 核电/工业园区 **周界 + 出入口 + 车牌**（固定摄像机，料号段 `1.0.01.04` / ITC）
- 场段、仓库、氢站外围的视频与门禁（合规优先于 AI 噱头）
- 轨交站/车辆段 CCTV，而不是车上 DSM

**不要切入（除非对方部门明确是车载）**

- Smart School Bus leftover check
- STOP ARM 北美校车法规逻辑（法国校车场景不同）

Assystem 的项目甲方往往是 EDF / SNCF / 工业主，集成商是有核电/工业资质的 national partner。厂商要和这些集成商一起进工程包，而不是单独拜访 Assystem 推销零售套装。

## 4. 和现有车载方案怎么接

2026 ON-BOARD 方案在法国要用「拆开卖」，不要整包硬推：

| 方案模块 | 法国设计院能不能写 | 0922 怎么落 |
|---|---|---|
| 固定 IPC / NVR | 能，Ingérop 弱电日常 | `1.0.01.04` / `1.0.01.23`，优先带 `-EUR` 或 DHI- 外部型号 |
| 客流双目 HMW8441 | 场站、公交门可以写 | `DH-IPC-HMW8441XP-M12-DAE-0200B-E` `1.0.01.02.11403-9002` |
| MXVR8212 车载主机 | 仅车队/公交运营商项目 | `DHI-DAE-MXVR8212-GFWI` `1.0.01.02.11805` |
| 360 PANA-S02 + CSV5122 | 公交/货车环视 | 注意 PPT 的 CVS 与 ERP 的 **CSV** 不一致 |
| IVSS 人脸 | 场站优惠卡、工业出入口；**RGPD 高风险** | 料号在 `1.0.01.23`，必须配 CNIL 用途说明 |
| DSM/ADAS | 车队主动安全，需 E-Mark / 车规 | PPT 未钉死单一料号，出图前要补法国可售型号 |

零售强 = 标准 IPC 参数表可以很快给 Ingérop 楼宇组；交通要另做 **路侧 CCTV + 车载** 两套一页纸，不要混成一份总部 PPT。

## 5. 建议动作（设计院拓展）

1. **Ingérop MES 弱电**：同城拜访，交付物 = 法语 CCTP 模块（视频保护 / 客流 / 车载三选一）+ 外部型号列表。
2. **指定 1～2 家 national partner** 作为 Ingérop 图纸的默认施工方，避免设计院问「谁安装」。
3. **Assystem**：走工业/能源 national partner，带周界+网安材料，不带校车方案。
4. **内部补课**：法国可售清单（EUR）、CNPP/网络安全声明、至少 1 个法国交通或工业参考项目。没有这三样，设计院很难把我们写进 PRO。

还缺、但现在可以开始用的：Ingérop/Assystem 具体对接人、法国授权价目、已中标 CCTP 摘录。有这些可以再把洞察收成「可投放的一页规格」。
